The Problem & The Solution

Why Black-Coat Was Built

In legal matters, an invented section number or inaccurate penalty clause is dangerous. Black-Coat replaces guesswork with verified statutory grounding.

❌

The Fatal Flaw with Generic AI

  • Section Hallucination: Models like ChatGPT confidently invent non-existent sub-clauses and punishments.
  • Colonial Law Confusion: Frequently cites repealed Indian Penal Code (IPC 1860) or CrPC 1973 instead of the new 2023 criminal codes.
  • Inability to Say "I Don't Know": When uncertain, generic models extrapolate plausibly sounding legal fiction.
  • Expensive Cloud Infrastructure: Commercial legal tools cost thousands of dollars per seat.
✅

The Black-Coat Architecture

  • Strict Statutory Grounding: Every response is generated strictly from retrieved sections of the India Code.
  • New 2023 Codes First: Versioned corpus tracks Bharatiya Nyaya Sanhita (BNS), BNSS, and BSA alongside legacy cross-mappings.
  • The Hard Refusal Gate: If statutory similarity is below 0.65, Black-Coat refuses to guess, returns a safe refusal, and refunds user quota.
  • Open-Source Architecture: Self-hostable and deployable on any cloud (Render, AWS, GCP) or local private infrastructure.
System Design Deep-Dive

How Black-Coat Works: The 5-Stage Verification Pipeline

Every user query undergoes strict multi-stage verification before tokens reach the screen.

01

Script & Language Detection (Zero LLM Overhead)

Analyzes Unicode blocks locally to detect Indic scripts (Devanagari for Hindi/Marathi, Tamil, Telugu, Bengali, Kannada) versus Latin for English in under 1ms without consuming LLM tokens.

02

Hybrid Statutory Retrieval (pgvector + FTS)

Executes two simultaneous queries across the legal database:
• Dense Vector Search: Top-20 cosine similarity on 1024-dim BGE-M3 embeddings via PostgreSQL HNSW index.
• Sparse Keyword Search: Top-20 full-text search using GIN on tsvector.
Both rankings are fused via Reciprocal Rank Fusion (RRF, k=60) to prioritize exact statutory matches.

03

The Hard Refusal Gate

If the highest-ranking statute falls below our 0.65 similarity threshold, the system terminates generation immediately. Zero LLM calls are made, preventing any hallucination, and the user's reserved query quota is refunded instantly.

04

Agentic Evaluation Pipeline

It will be an agentic pipeline for evaluation: an autonomous multi-agent evaluator cross-examines statutory interpretations, validates premise logic against India Code, and ensures strict alignment before final response synthesis.

05

Citation Verification & Safety Layer

The post-processor parses every [S#] citation tag and matches it against database IDs. Unknown or hallucinated tags are stripped, and ungrounded free-text sections are flagged. Urgent custody or violence queries automatically append official Indian legal aid helplines (112 & NALSA 15100).

Statutory Coverage

Indian Legal Corpus Supported

Black-Coat is purpose-built for the historic transition to the 2023 criminal codes with versioned corpus tracking.

Primary Criminal Code

Bharatiya Nyaya Sanhita, 2023 (BNS)

Replaces the Indian Penal Code, 1860 (IPC). Covers offenses against person, property, state, organized crime, and modern financial fraud.

Criminal Procedure

Bharatiya Nagarik Suraksha Sanhita, 2023 (BNSS)

Replaces the Code of Criminal Procedure, 1973 (CrPC). Governs arrest procedures, custody timelines, zero-FIR, and bail standards.

Evidence & Admissibility

Bharatiya Sakshya Adhiniyam, 2023 (BSA)

Replaces the Indian Evidence Act, 1872 (IEA). Regulates electronic records, secondary evidence, and digital forensics admissibility.

Fundamental Law

Constitution of India & Special Acts

Fundamental Rights (Part III), POCSO Act, Information Technology Act (cyber fraud), and Protection of Women from Domestic Violence Act.
