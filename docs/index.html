Engineered for Correctness

High-Performance Modular Monolith

Designed to run on a single free JVM with zero network hops and rock-solid boundaries.

🔍

Hybrid pgvector + FTS

Combines dense multilingual BGE-M3 embeddings on HNSW with PostgreSQL full-text search (tsvector) using Reciprocal Rank Fusion (RRF).

🔄

Resilience4j Provider Chain

Cascades from Gemini 1.5/2.0 Flash to Groq Llama 3.3 70B, with local Ollama fallback when cloud APIs are rate-limited.

🛡️

Atomic Quotas & Grounding

Atomic PostgreSQL reservation (10/day, 100/month) that automatically refunds queries if no verified law satisfies the similarity gate.

🇮🇳

Multilingual Indic Scripts

Local script detection identifies Hindi, Tamil, Telugu, Bengali, and Marathi queries without consuming external LLM tokens.
